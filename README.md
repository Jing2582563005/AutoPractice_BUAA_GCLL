# 北航工程伦理刷题脚本-2026

使用方法：

1.在篡改猴里面添加脚本

2.分为需要**手动提交的测试版**和**自动刷题版**，测试版会自动选择完成后不提交，等你手动提交。

3.使用时，需要打开测试题的页面，然后等待做完就可以。再选择下一个作业
